#Inventory Tracker & Inventory Valuation Report

A command-line Python tool that records inventory items into a CSV file and generates a stock and valuation summary report. 
The project is designed for IT support, field technicians, and operations teams who need a lightweight inventory logging system for 
spare parts and maintenance supplies.

## Features

* Add Inventory items from the Linux terminal
* Record quantity received and unit cost
* Automatic timestamp generation
* CSV header creation on first run
* Append inventory records without overwriting existing data
* Multiple inventory entries in one session
* Stock summary per item
* Total inventory value per item
* Grand total inventory valuation report

## Technologies Used

* Python 3
* datetime
* os.path
* csv
* Linux command line
